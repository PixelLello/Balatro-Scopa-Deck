# Balatro Scopa Deck Mod

This mod for Balatro Adds Traditional Napolitan Cards to the game as Custom Skins

- Hearts ---> Cups
- Diamonds ---> Pentacles
- Club ---> Wands
- Spades ---> Swords

I hope you like this mod ;)
